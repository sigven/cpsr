# Variant labels for the key findings: gene symbol (bold) and protein change (or coding DNA change for non-coding variants), with zygosity for homozygous variants - ordered by gene symbol, then alteration

Variant labels for the key findings: gene symbol (bold) and protein
change (or coding DNA change for non-coding variants), with zygosity for
homozygous variants - ordered by gene symbol, then alteration

## Usage

``` r
variant_labels_hl(d)
```

## Arguments

- d:

  variant data frame (display columns SYMBOL, ALTERATION, and optionally
  GENOTYPE)
