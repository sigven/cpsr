# Function that retrieves pharmacogenomic variants based on ClinVar classifications (legacy approach, used for data bundles without CPIC allele definitions)

Function that retrieves pharmacogenomic variants based on ClinVar
classifications (legacy approach, used for data bundles without CPIC
allele definitions)

## Usage

``` r
retrieve_pgx_calls_clinvar(calls)
```

## Arguments

- calls:

  data frame with all calls found
