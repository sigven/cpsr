# Colored pill (rounded box with white, bold text) in a PDF report table cell - raw Typst markup; the column must not be escaped by format_tt()

Colored pill (rounded box with white, bold text) in a PDF report table
cell - raw Typst markup; the column must not be escaped by format_tt()

## Usage

``` r
pill_pdf(label, fill)
```

## Arguments

- label:

  pill text(s)

- fill:

  background color(s) (hex)

## Value

character vector with Typst markup ("" for empty labels)
