# CPIC phenotypes as colored pills in a PDF report table - blues, darker for more impact (pgx_phenotype_color, as in the HTML report)

for more impact (pgx_phenotype_color, as in the HTML report)

## Usage

``` r
pgx_phenotype_pill_pdf(phenotypes)
```

## Arguments

- phenotypes:

  CPIC phenotype per table row

## Value

character vector with Typst markup (see pcgrr::pdf_pill())
