# Biomarker evidence sources (CIViC, CGI) as logos (Typst markup) - images copied with the templates to the rendering directory (typst/logo\_\*.png); unknown sources as plain text

Biomarker evidence sources (CIViC, CGI) as logos (Typst markup) - images
copied with the templates to the rendering directory
(typst/logo\_\*.png); unknown sources as plain text

## Usage

``` r
bm_source_logo_pdf(sources, height = "1.4em")
```

## Arguments

- sources:

  source identifiers (e.g. 'civic', 'cgi')

- height:

  logo height (Typst length)
