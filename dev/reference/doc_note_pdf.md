# Convert the HTML elements of a documentation note (markdown with inline HTML, as used in the HTML report) to markdown, for the PDF report

Convert the HTML elements of a documentation note (markdown with inline
HTML, as used in the HTML report) to markdown, for the PDF report

## Usage

``` r
doc_note_pdf(x)
```

## Arguments

- x:

  documentation note (character)

## Value

documentation note with **/ *as markdown emphasis, and line breaks (  
) removed***
