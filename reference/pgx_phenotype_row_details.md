# Row details (variant level) for the CPIC phenotype table

Row details (variant level) for the CPIC phenotype table

## Usage

``` r
pgx_phenotype_row_details(phenotypes, variants = NULL)
```

## Arguments

- phenotypes:

  data frame with gene phenotypes

- variants:

  data frame with pharmacogenomic variants

## Value

function(index) for reactable details
