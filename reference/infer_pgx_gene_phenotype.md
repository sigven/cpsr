# Infer CPIC phenotype for a single gene

Infer CPIC phenotype for a single gene

## Usage

``` r
infer_pgx_gene_phenotype(gene_hits, gene_phenotypes, sex = "UNKNOWN")
```

## Arguments

- gene_hits:

  allele matches (match_pgx_alleles) for the gene, altered function
  alleles only

- gene_phenotypes:

  CPIC function/activity value to phenotype mappings for the gene

- sex:

  sample sex ('MALE', 'FEMALE' or 'UNKNOWN')
