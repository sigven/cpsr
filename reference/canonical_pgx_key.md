# Canonical (sorted) representation of a CPIC lookup key

Canonical (sorted) representation of a CPIC lookup key

## Usage

``` r
canonical_pgx_key(key_elements)
```

## Arguments

- key_elements:

  character vector with lookup key elements, e.g. c('1.0:1', '0.5:1') or
  c('TPMT:Normal Metabolizer', 'NUDT15:...')
