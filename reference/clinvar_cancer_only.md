# Whether ClinVar variants attributed to non-cancer phenotypes only should be excluded (option –clinvar_cancer_only)

Whether ClinVar variants attributed to non-cancer phenotypes only should
be excluded (option –clinvar_cancer_only)

## Usage

``` r
clinvar_cancer_only(conf = NULL)
```

## Arguments

- conf:

  CPSR configuration object with run settings

## Value

logical; FALSE if the setting is absent
