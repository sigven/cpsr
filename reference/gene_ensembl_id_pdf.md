# Ensembl gene ids of gene symbols, looked up among the variants of the report (all variant sets) and the genes of the virtual panel

Ensembl gene ids of gene symbols, looked up among the variants of the
report (all variant sets) and the genes of the virtual panel

## Usage

``` r
gene_ensembl_id_pdf(report, symbol)
```

## Arguments

- report:

  CPSR report object

- symbol:

  gene symbol(s)

## Value

Ensembl gene id per symbol (NA if not found)
