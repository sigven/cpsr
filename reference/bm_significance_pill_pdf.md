# Biomarker clinical significance as colored pills (Typst markup) for the PDF report - colors as in the HTML report (rt_cell_bm_significance)

Biomarker clinical significance as colored pills (Typst markup) for the
PDF report - colors as in the HTML report (rt_cell_bm_significance)

## Usage

``` r
bm_significance_pill_pdf(significance)
```

## Arguments

- significance:

  clinical significance per table row (e.g. 'Sensitivity/Response',
  'Poor Outcome')

## Value

character vector with raw Typst markup (rounded box with white, bold
text); unknown categories in grey
